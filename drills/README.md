# Drills

Small, curated hardening exercises — not a bulk problem set. Bulk algorithm practice
(LeetCode/NeetCode style) happens on those platforms directly.

Each drill takes a problem whose concept is about to matter in `project/` (e.g. a
heap/priority-queue problem right before a holds-priority feature) and turns it into
reviewable, production-shaped code: idiomatic Java, edge cases handled, a unit test, and a
short complexity comment.

## Adding a drill

1. Create a numbered folder: `NNN-<short-slug>/` (e.g. `001-two-sum/`).
2. Inside it: the solution class, its test, and a one-paragraph `NOTES.md` on approach and
   time/space complexity.
3. Submit it as a PR like any project change — same review bar applies.
