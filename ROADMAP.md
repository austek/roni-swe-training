# Curriculum Roadmap

Steady pace, not deadline-driven — but ramps from fundamentals to interview-level polish.

## Phase 1 — Foundations
Git workflow, clean code, first flagship features (entities, basic CRUD). No drills yet —
bulk practice on arrays/strings/hashmaps stays on LeetCode/NeetCode.

## Phase 2 — Core SWE practices
Testing (JUnit), validation, exception handling, code review habits. First drills:
recursion/trees, timed to project needs.

## Phase 3 — Depth
Persistence layer design, business rule complexity (fees, holds). Drills: heaps/graphs/DP
as project features call for them.

## Phase 4 — Job-readiness polish
Auth, API design polish, a couple of LLD-style drills, mock review rigor, a resume-ready
README on the flagship project.
